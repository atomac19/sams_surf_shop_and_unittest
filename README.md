# Sam's Surf Shop project

## Description
This project is exercise my knowledge of errors and unit testing practice in Python.
I create a handful of tests for the shopping cart software at the surf shop.

## Features
When that was done, I implement some improvements for thes tests using more advanced unit testing features, like:
  - skipping
  - parameterization
  - expected failures.
Finally, I fix bugs that were exposed by my tests.

  - unittest
